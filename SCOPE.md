# Область реализации Revit MCP 0.0.2

Поддерживаемая платформа — Autodesk Revit 2026 / Windows x64. Описание операций — в [руководстве](docs/USAGE.md), транспорт и идентификаторы — в [архитектуре](docs/ARCHITECTURE.md).

| Область | Реализовано |
| --- | --- |
| Проект и виды | Чтение проекта, активного вида, выделения, параметров, типов, статистики |
| Поиск | Категории, уровни, виды, сравнения параметров и единицы, страницы, сводки, пространственные ограничения, геометрические опоры |
| Редактирование | Перемещение и вращение существующих элементов, смена типа, полное постраничное чтение параметров экземпляра и типа |
| Помещения и материалы | Чтение площадей, периметров, объёмов и количеств |
| Архитектура | Прямые стены, перекрытия, потолки, помещения, разделители, одноуровневые семейства, двери и окна |
| Конструкции | Прямые балки, оси, прямоугольные балочные системы, двускатная кровля |
| Инженерные системы | Прямые трубы и воздуховоды; чтение коннекторов ОВ/ВК; соединение выбранной пары напрямую, через отвод, муфту или переход |
| Виды и оформление | Планы, разрезы, стадии видов, графика, размеры, марки стен, помещений и 12 категорий ОВ/ВК |
| Документация | Каталоги всех видов/шаблонов/спецификаций, чтение листов страницами, аннотации и параметры; создание и настройка спецификаций |
| Листы | Формат по основной надписи, копии видов, экспликации, компоновка и текст; имя, номер и коллекция |
| Семейства | [Чтение и создание RFA](docs/FAMILIES.md), параметры и формулы, TXT-каталоги, выдавливания и пустоты, HVAC-разъёмы, вложения, сохранение копии и повторная проверка |
| Файлы | Сохранение RVT, PNG/JPG/BMP/TIFF/PDF видов, CSV спецификаций, IFC/gbXML модели и локальные JSON-снимки |
| Подключение | Обнаружение процессов Revit, явный выбор PID, независимый профиль инструментов «только чтение» |
| Выполнение | Предпросмотр с откатом, план по ревизии документа, подтверждение и локальное автоподтверждение |
| Обновление | Стабильный и отдельно включаемый бета-канал; прогресс загрузки, проверки и распаковки; переключение рабочей части без перезапуска Revit, возврат предыдущей сборки |
| Установка | EXE для текущего пользователя, включённые зависимости, конфигурации MCP, восстановление и удаление |

Не реализованы автоматическая трассировка MEP, автоматическое устранение коллизий и наложений, универсальная обработка связанных моделей, произвольный C# и поддержка других версий Revit. Наличие операции в коде не означает проверки каждого сочетания семейств и типов.
