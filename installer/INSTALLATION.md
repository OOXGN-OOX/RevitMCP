# Установка Revit MCP

1. Сохраните проекты, закройте Revit и запустите `RevitMCP-0.0.2-Setup.exe`.
2. Выберите Codex и/или Claude Desktop, нажмите **Установить**.
3. Запустите Revit 2026 и перезапустите MCP-клиент.

Требуются Windows x64 и Autodesk Revit 2026. Node.js, MCP-зависимости и среда .NET включены в EXE. Файлы не подписаны сертификатом издателя.

## Обновление

Откройте **Revit MCP → Обновление → Проверить → Обновить**. Интернет нужен только для проверки и загрузки. Рабочая часть и значки заменяются без закрытия Revit. Кнопка **Вернуть предыдущую** восстанавливает предыдущую установленную сборку. После переключения создайте новые предпросмотры операций.

Для перехода на выбор каналов и новые MEP-инструменты установите полный пакет с закрытым Revit и перезапустите MCP-клиент. Требуется загрузчик `0.0.2.1`. Кнопка обновляет рабочую часть совместимого протокола; новый загрузчик, Node.js или схемы MCP устанавливаются полным пакетом.

По умолчанию включён стабильный канал опубликованных выпусков из `main`. Тестовые сборки `0.0.2` доступны при включённом флажке **Получать бета-обновления**. Выбор сохраняется в `Application/update-settings.json`; после смены канала нажмите **Проверить**. Отключение beta не понижает установленную версию. Прогресс показывает загрузку, проверку, распаковку и ожидание свободного контекста Revit.

При ошибке загрузки или проверки действующая сборка продолжает работать. Диагностика обновления — `%LOCALAPPDATA%\RevitMCP\update.log`.

## Файлы и подключение

Программа: `%LOCALAPPDATA%\RevitMCP\Application`. Манифест: `%APPDATA%\Autodesk\Revit\Addins\2026\RevitMCP.addin`. Настройки подключения для других клиентов — в `Application/versions/0.0.2/connection`. TCP-мост: `127.0.0.1:37652`.

Установщик меняет только запись `revit_mcp` и сохраняет резервные конфигурации в `%LOCALAPPDATA%\RevitMCP\backups`. Для работы моста порт должен быть свободен от других надстроек.

## Восстановление и удаление

Повторный запуск установщика восстанавливает начальную рабочую часть. Перед установкой и удалением закройте Revit; перед удалением также закройте MCP-клиент.

Удаление: **Параметры Windows → Приложения → Revit MCP**. Модели, снимки, токен, настройки и резервные конфигурации сохраняются.

```text
RevitMCP-0.0.2-Setup.exe --silent --codex --claude --auto-confirm
```

Флаги клиентов и автоподтверждения необязательны. Нестандартный каталог: `--revit="D:\Autodesk\Revit 2026"`. Код возврата: 0 — успех, 1 — ошибка. Диагностика установки: `%LOCALAPPDATA%\RevitMCP\setup.log`.
