# Установка Revit MCP

1. Сохраните проекты и закройте Revit. Запустите `RevitMCP-0.0.1-Setup.exe`.
2. Выберите Codex и/или Claude Desktop. Автоподтверждение включайте только при необходимости.
3. Нажмите **Установить**, затем запустите Revit 2026 и перезапустите MCP-клиент.

Windows x64, Autodesk Revit 2026 и доступ к его установленному каталогу обязательны. Интернет и SDK на компьютере пользователя не требуются. Файлы надстройки пока не подписаны сертификатом издателя.

## Файлы и подключение

Программа: `%LOCALAPPDATA%\RevitMCP\Application`. Манифест: `%APPDATA%\Autodesk\Revit\Addins\2026\RevitMCP.addin`. Конфигурации другого MCP-клиента: `Application\versions\0.0.1\connection`. MCP-мост слушает `127.0.0.1:37652`.

Установщик обновляет только запись `revit_mcp` и сохраняет другие серверы. Резервные конфигурации и манифесты находятся в `%LOCALAPPDATA%\RevitMCP\backups`. Каталоги и настройки других надстроек автоматически не переносятся. Если включена другая надстройка с похожими MCP-инструментами, выбирайте соответствующее подключение в клиенте.

## Восстановление и удаление

Повторный запуск восстанавливает файлы текущей версии. Версии хранятся отдельно. Перед установкой или удалением закройте Revit; перед удалением также закройте MCP-клиент.

Удаление: **Параметры Windows → Приложения → Установленные приложения → Revit MCP**. Удаляются файлы программы и принадлежащее ей подключение; RVT, снимки, токен, настройки и резервные конфигурации сохраняются.

## Автоматическая установка

```text
RevitMCP-0.0.1-Setup.exe --silent --codex --claude --auto-confirm
```

Все флаги клиентов и автоподтверждения необязательны. Без флагов клиентов их настройки не меняются. Нестандартный каталог: `--revit="D:\Autodesk\Revit 2026"`. Код возврата: 0 — успех, 1 — ошибка. Диагностика: `%LOCALAPPDATA%\RevitMCP\setup.log`.
