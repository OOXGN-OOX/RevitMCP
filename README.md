<h1 align="center">Revit MCP</h1>

<p align="center">Локальный MCP-мост для работы с моделью и документацией Autodesk Revit.</p>
<p align="center"><strong>Версия 0.0.1 · OOXGN</strong><br>Revit 2026 · Windows x64 · C# / .NET 8 · Node.js</p>

## Возможности

| Задача | Инструменты |
| --- | --- |
| Чтение модели | Проект, виды, элементы, параметры, семейства, помещения и материалы |
| Моделирование | Стены, перекрытия, потолки, балки, оси, уровни, помещения, двери и окна |
| Инженерные системы | Прямые сегменты труб и воздуховодов, нативные марки ОВ/ВК |
| Оформление | Размеры, марки, текст, листы А3, экспликации и компоновка видов |
| Выпуск и обмен | PNG видов, PDF листов, сохранение RVT и локальные JSON-снимки |

Изменения выполняются через пары `preview_*` / `apply_*` с проверкой документа и транзакциями Revit. Подробности и ограничения — в [руководстве](docs/USAGE.md) и [области реализации](SCOPE.md).

## Установка

1. Скачайте `RevitMCP-0.0.1-Setup.exe` из [Releases](https://github.com/OOXGN-OOX/RevitMCP/releases/tag/v0.0.1).
2. Закройте Revit, запустите установщик и выберите нужный MCP-клиент.
3. Запустите Revit 2026 и перезапустите клиент. Вкладка надстройки — **Revit MCP**.

Node.js, зависимости и среда .NET включены в EXE. Требуется отдельно установленный Revit 2026. Установка выполняется для текущего пользователя. [Установка, восстановление и удаление](installer/INSTALLATION.md).

## Быстрый запуск

1. Откройте проект и вызовите `get_project_info`.
2. Прочитайте существующие типы, уровни и геометрию.
3. Выполните `preview_*`, затем соответствующий `apply_*` с полученным `planId`.
4. Проверьте результат в Revit и сохраните проект.

Кнопка **Подключение** показывает состояние моста. **Авто подтверждение** переключает локальный режим выполнения; по умолчанию изменения требуют подтверждения в Revit.
