Локальный MCP-мост для работы с моделью и документацией Autodesk Revit 2026. Windows x64, .NET 8.

## Возможности

- Чтение проекта, видов, элементов, параметров, семейств, помещений и материалов.
- Создание архитектурных элементов, прямых труб и воздуховодов.
- Размеры, марки, листы А3, экспликации и компоновка видов.
- Экспорт PNG и PDF, сохранение RVT и локальные JSON-снимки.
- Предпросмотр изменений, подтверждение и транзакции Revit.
- Обновление рабочей части плагина по кнопке, с возвратом к предыдущей сборке.

## Установка

Тестовые сборки 0.0.2 доступны в артефактах успешных запусков [Build and test](https://github.com/OOXGN-OOX/RevitMCP/actions/workflows/build.yml?query=branch%3A0.0.2). Для скачивания артефакта требуется вход в GitHub.

1. Скачайте артефакт `RevitMCP-0.0.2-<commit>`, распакуйте его и запустите `RevitMCP-0.0.2-Setup.exe` с закрытым Revit.
2. Выберите MCP-клиент, установите плагин и запустите Revit 2026.
3. Перезапустите MCP-клиент и вызовите `get_project_info`.

Node.js, зависимости и среда .NET включены в установщик. На вкладке **Revit MCP** доступны **Подключение**, **Авто подтверждение** и **Обновление**. После установки загрузчика обновления рабочей части применяются без закрытия Revit. Изменение самого загрузчика или схем MCP требует отдельной установки. [Установка и восстановление](installer/INSTALLATION.md).
