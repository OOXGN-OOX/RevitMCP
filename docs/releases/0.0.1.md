# Revit MCP 0.0.1

Первый выпуск Revit MCP под брендом издателя OOXGN для Autodesk Revit 2026 / Windows x64.

- Нейтральное название продукта в ленте, диалогах, MCP-сервере и установщике.
- Собственные DLL/namespace, AddInId, MCP-запись `revit_mcp`, каталог данных `RevitMCP` и порт `37652`.
- Монохромные знаки OOXGN и тёмное оформление установщика.
- Автоматические тесты, сборка DLL и выпуск EXE через GitHub Actions без установленного Revit на runner.
- Чтение и изменение модели, оформление, марки ОВ/ВК, листы А3, PNG/PDF и локальные снимки.
- Сохранены AGPL-3.0-only, авторство исходного проекта и соответствующие исходники.

## Установка

Закройте Revit и запустите `RevitMCP-0.0.1-Setup.exe`. Выберите MCP-клиент, установите надстройку, затем откройте Revit и перезапустите клиент. Node.js, зависимости и .NET включены. Autodesk Revit устанавливается отдельно.

Файлы выпуска: установщик, соответствующие исходники, SHA-256 и английские промпты для новых графических материалов. Индивидуальная ICO-иконка EXE и обложки в этой версии отсутствуют; используются готовые векторные знаки OOXGN и стандартный значок Windows.

Версия экспериментальная. Поддерживается только Revit 2026; операции записи и семейства проверяйте на копии проекта. Ограничения: [руководство](https://github.com/OOXGN-OOX/RevitMCP/blob/v0.0.1/docs/USAGE.md). Повторная установка и удаление сохраняют пользовательские данные и сторонние MCP-серверы.
