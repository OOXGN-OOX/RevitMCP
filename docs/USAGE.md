# Работа с Revit MCP

[← Revit MCP](../README.md)

## Подключение

Откройте Revit 2026 и проект. Вызовите `get_running_revit_instances`, затем `get_project_info`; если процессов несколько, передавайте выбранный `processId` в каждом запросе. `revit_ping` возвращает версию DLL и состояние `autoConfirm`. На вкладке **Revit MCP** кнопка **Подключение** показывает проект, порт, версию и номер сборки; она также повторно запускает мост после сбоя подключения.

[Инструменты модели](MODEL.md): полные параметры, поиск по значениям, перемещение и вращение, смена типа, спецификации, коллекции листов, графика, IFC/gbXML/CSV и режим «только чтение».

## Чтение и изменение

Сначала прочитайте существующие уровни, типы, параметры и геометрические опоры. Затем выполните нужный `preview_*` и соответствующий `apply_*` с `planId`. Временные ID объектов из предпросмотра не используются как постоянные ID модели. Проверьте результат визуально и сохраните проект.

| Задача | Инструменты |
| --- | --- |
| Запись параметров, включая ElementId | `get_parameter_value_options`, `preview_set_parameter` / `apply_parameter_plan`; [формат значений](PARAMETERS.md) |
| Двери и окна | `preview_place_hosted_families` / `apply_place_hosted_families` |
| Новые типоразмеры | `preview_duplicate_family_types` / `apply_duplicate_family_types` |
| Имя семейства или типоразмера | `preview_rename_family` / `apply_rename_family` |
| MEP-коннекторы | `list_mep_connectors`, `preview_connect_mep` / `apply_connect_mep` |
| Разработка RFA | `read_family_file`, `read_family_type_catalog`, `preview_build_family` / `apply_build_family`, `validate_family_file` |
| Выгрузка RFA из проекта/вложения | `preview_export_family` / `apply_export_family`, `preview_export_nested_family` / `apply_export_nested_family`; [проверки и ограничения](FAMILY-EXPORT.md) |
| Загрузка локального RFA | `preview_load_family` / `apply_load_family` |
| Размеры по опорам | `list_annotation_types`, `get_element_references`, `preview_create_dimensions` / `apply_create_dimensions` |
| Марки | `preview_tag_walls`, `preview_tag_rooms`, `preview_tag_mep` и соответствующие `apply_*` |
| Оформление эталона | `read_documentation` |
| Графика элементов | `preview_element_graphics` / `apply_element_graphics` |
| Раскраска по параметру | `preview_color_by_parameter` / `apply_color_by_parameter` |
| Листы А3 и экспликации | `list_sheet_resources`, `preview_create_sheets` / `apply_create_sheets` |
| Компоновка и текст | `preview_finish_sheet` / `apply_finish_sheet` |
| Вывод | `export_view_image`, `export_sheets_pdf` |
| Удаление | `preview_delete_elements` / `apply_delete_plan` |

Полный набор и схемы аргументов доступны через MCP `tools/list`.

Порядок чтения и соединения MEP-коннекторов — в [руководстве по MEP](MEP.md).

## Подтверждение

По умолчанию `apply_*` запрашивает подтверждение в Revit; отказ выбран по умолчанию. Кнопка **Авто подтверждение** переключает локальную настройку `%LOCALAPPDATA%\RevitMCP\settings.json`: `{"autoConfirm":true}`. Настройка перечитывается перед операцией.

Автоматический режим распространяется на все `apply_*`, включая удаление и SaveAs. Проверки preview, planId, ревизии документа и транзакций продолжают действовать. При удалении зависимых элементов требуется явное `allowDependentDeletion=true`; расхождение с рассчитанным набором вызывает откат.

Разработка семейств из RFA/RFT, каталогов типов, геометрии и HVAC-разъёмов описана в [руководстве по семействам](FAMILIES.md). Эти инструменты работают со скрытыми документами и не требуют активного проекта. Перезагрузка RFA в проект требует явных `parameterPolicy` и `sharedFamilySource`.

## Ограничения

- Двери и окна размещаются на прямых вертикальных базовых стенах с подходящими существующими семействами. Нестандартные хосты и все варианты семейств не поддерживаются.
- Размеры линейные, по явным стабильным опорам; автоматический подбор всех опор, угловые и дуговые размеры отсутствуют.
- Марки ОВ/ВК используют существующие типы для 12 категорий. Положение головок и выносок задаётся явно; наложения проверяются визуально.
- Трубы и воздуховоды создаются прямыми сегментами. Соединение выполняется отдельной операцией по двум выбранным свободным коннекторам: напрямую, через отвод, муфту или переход. Автоматическая трассировка, тройники и врезки отсутствуют.
- Кровля ограничена прямоугольным двускатным контуром; балочные системы — горизонтальным прямоугольником с фиксированным шагом.
- Листы А3 используют существующую основную надпись. Соответствие ГОСТ, пересечения, подписи и заполнение штампа проверяются отдельно по чертежу и PDF.
- Связанные модели, универсальное копирование оформления и произвольное выполнение C# не входят в область реализации.
- Другие надстройки могут реагировать на события пробных транзакций; их внешние действия мост не контролирует.

Полная проверка записывающих сценариев на всех категориях и семействах не заявляется. Перед рабочим применением проверьте нужный сценарий на копии RVT.

## Обновление

На вкладке **Revit MCP** нажмите **Обновление**, затем **Проверить**. Если доступна новая совместимая сборка, нажмите **Обновить**. Во время загрузки можно нажать **Отмена**. Применение ожидает свободного контекста Revit; завершите открытый диалог или текущую команду.

По умолчанию проверяется стабильный канал опубликованных выпусков из `main`. Для тестовых сборок включите **Получать бета-обновления** и снова нажмите **Проверить**. Настройка сохраняется между запусками. Выключение beta меняет источник следующих обновлений и не заменяет уже установленную сборку. Если стабильные выпуски ещё не опубликованы, окно сообщает об этом.

Окно показывает процент и объём загрузки, проверку контрольной суммы, распаковку и ожидание Revit. Отмена доступна во время загрузки, проверки, распаковки и ожидания переключения.

После успешного переключения продолжайте работу в том же документе. Старые planId перестают действовать — выполните preview заново. Для возврата нажмите **Вернуть предыдущую**. Кнопка обновляет рабочую часть и значки; загрузчик и схемы MCP обновляются отдельной установкой. Проверка по кнопке использует интернет, фоновый опрос отсутствует.
