# Работа с Revit MCP

[← Revit MCP](../README.md)

## Подключение

Откройте Revit 2026 и проект, затем вызовите `get_project_info`. `revit_ping` возвращает версию DLL и состояние `autoConfirm`. На вкладке **Revit MCP** кнопка **Подключение** показывает проект, порт, версию и издателя; она также повторно запускает мост после сбоя подключения.

## Чтение и изменение

Сначала прочитайте существующие уровни, типы, параметры и геометрические опоры. Затем выполните нужный `preview_*` и соответствующий `apply_*` с `planId`. Временные ID объектов из предпросмотра не используются как постоянные ID модели. Проверьте результат визуально и сохраните проект.

| Задача | Инструменты |
| --- | --- |
| Двери и окна | `preview_place_hosted_families` / `apply_place_hosted_families` |
| Новые типоразмеры | `preview_duplicate_family_types` / `apply_duplicate_family_types` |
| Загрузка локального RFA | `preview_load_family` / `apply_load_family` |
| Размеры по опорам | `list_annotation_types`, `get_element_references`, `preview_create_dimensions` / `apply_create_dimensions` |
| Марки | `preview_tag_walls`, `preview_tag_rooms`, `preview_tag_mep` и соответствующие `apply_*` |
| Оформление эталона | `read_documentation` |
| Графика элементов | `preview_element_graphics` / `apply_element_graphics` |
| Раскраска по параметру | `preview_color_by_parameter` / `apply_color_by_parameter` |
| Листы А3 и экспликации | `list_sheet_resources`, `preview_create_sheets` / `apply_create_sheets` |
| Компоновка и текст | `preview_finish_sheet` / `apply_finish_sheet` |
| Вывод | `export_view_image`, `export_sheets_pdf` |
| Удаление | `preview_delete_elements` / `apply_delete_plan` |

Полный набор и схемы аргументов доступны через MCP `tools/list`.

## Подтверждение

По умолчанию `apply_*` запрашивает подтверждение в Revit; отказ выбран по умолчанию. Кнопка **Авто подтверждение** переключает локальную настройку `%LOCALAPPDATA%\RevitMCP\settings.json`: `{"autoConfirm":true}`. Настройка перечитывается перед операцией.

Автоматический режим распространяется на все `apply_*`, включая удаление и SaveAs. Проверки preview, planId, ревизии документа и транзакций продолжают действовать. При удалении зависимых элементов требуется явное `allowDependentDeletion=true`; расхождение с рассчитанным набором вызывает откат.

## Ограничения

- Двери и окна размещаются на прямых вертикальных базовых стенах с подходящими существующими семействами. Нестандартные хосты и все варианты семейств не поддерживаются.
- Размеры линейные, по явным стабильным опорам; автоматический подбор всех опор, угловые и дуговые размеры отсутствуют.
- Марки ОВ/ВК используют существующие типы для 12 категорий. Положение головок и выносок задаётся явно; наложения проверяются визуально.
- Трубы и воздуховоды создаются прямыми сегментами без автоматической трассировки, фитингов и соединений.
- Кровля ограничена прямоугольным двускатным контуром; балочные системы — горизонтальным прямоугольником с фиксированным шагом.
- Листы А3 используют существующую основную надпись. Соответствие ГОСТ, пересечения, подписи и заполнение штампа проверяются отдельно по чертежу и PDF.
- Связанные модели, универсальное копирование оформления и произвольное выполнение C# не входят в область реализации.
- Другие надстройки могут реагировать на события пробных транзакций; их внешние действия мост не контролирует.

Полная проверка записывающих сценариев на всех категориях и семействах не заявляется. Перед рабочим применением проверьте нужный сценарий на копии RVT.
