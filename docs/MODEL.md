# Работа с моделью, спецификациями и экспортом

[← Руководство](USAGE.md)

Платформа — Revit 2026. Эти инструменты входят в пакет `0.0.2` с загрузчиком `0.0.2.4` и соответствующим MCP-сервером. Для перехода с предыдущего загрузчика нужен полный установщик и перезапуск Revit и MCP-клиента.

## Подключение и доступ

`get_running_revit_instances` возвращает доступные процессы Revit с установленным мостом, их PID и имя активного документа. Мост проверяет ответ каждого процесса; устаревшие записи не включаются.

Если процесс один, `processId` можно не передавать. Если их несколько, передавайте выбранный PID в каждом запросе, включая `preview_*` и `apply_*`. План относится к документу внутри выбранного процесса. Переключение проекта или изменение модели может потребовать нового предпросмотра.

Для подключения только инструментов чтения задайте переменную окружения MCP-сервера `REVIT_MCP_ACCESS=read`. По умолчанию используется `write`. В режиме `read` отсутствуют инструменты `preview_*`, `apply_*`, пробное создание спецификации для чтения доступных полей, проверка RFA с временными проектами и экспорт модели с транзакцией. Выделение, приближение, открытие видов и экспорт видов остаются доступны: эти действия не редактируют модель. Режим доступа не зависит от стабильного или бета-канала обновлений.

## Поиск и параметры

`search_elements` поддерживает `levelId`, `viewId` и массив `parameterFilters`. Все фильтры объединяются условием «И». Каждый фильтр содержит:

- `parameterId` или `parameterName` — ровно один идентификатор. При совпадающих именах используйте ID.
- `scope`: `instance` или `type`.
- `operator`: `equals`, `notEquals`, `contains`, `startsWith`, `endsWith`, `greaterThan`, `greaterOrEqual`, `lessThan`, `lessOrEqual`, `hasValue`, `hasNoValue`.
- `value` — число или строка; не требуется для проверки заполненности.
- `unitId` — необязательный ForgeTypeId единицы для числового параметра.

Без `unitId` числовые значения задаются во внутренних единицах Revit. Строки сравниваются без учёта регистра; для числового сравнения не передавайте форматированную строку. Результат содержит страницы элементов и сводку по категориям и уровням для всего найденного набора.

`get_element_properties` возвращает класс, габаритный параллелепипед с преобразованием координат, геометрию расположения и параметры. `parameterScope=both` включает параметры экземпляра и типа. Для параметра возвращаются ID, GUID общего параметра, тип данных, единица, исходное и отображаемое значение, заполненность и доступность записи.

Параметры выдаются страницами: `parameterOffset`, `parameterLimit` (1–500). Пока `parameterHasMore=true`, запрашивайте следующую страницу. Для большого числа параметров уменьшайте пакет элементов, чтобы ответ помещался в лимит 8 МБ.

## Редактирование существующих элементов

| Предпросмотр | Действие |
| --- | --- |
| `preview_move_elements` | Перемещение по вектору `translation={x,y,z}` в метрах |
| `preview_rotate_elements` | Поворот вокруг оси `axisStart`–`axisEnd`, угол `angleDegrees` |
| `preview_change_element_types` | Смена типа по `typeId` с проверкой совместимости |
| `preview_edit_sheet` | Имя, номер и коллекция листа |
| `preview_tag_elements` | Марки заданного типа для выбранных элементов на виде |

Каждой операции соответствует `apply_…` с `planId`. Закреплённые элементы и члены групп отклоняются при перемещении, вращении и смене типа. Revit проверяет хосты, ограничения и соединения при пробной транзакции. Просмотрите предупреждения перед применением. Смена типа может заменить элемент: используйте возвращённое соответствие `oldElementId` → `elementId`.

`show_elements` приближает активный вид к видимым элементам. `select_elements` меняет выделение, `activate_view` открывает вид.

## Виды, листы и помещения

- `list_views`: все виды, шаблоны или спецификации; включает неразмещённые виды. Фильтр `kind`, страницы `offset`/`limit`.
- `list_sheet_collections`: коллекции и их листы; необязательный `collectionId`.
- `read_documentation`: состав листов, размещение, графика, спецификации и аннотации.
- `get_room_boundaries`: контуры помещений по граням отделки, центрам или границам ядра. Координаты в метрах; кривые представлены тесселированными точками с указанием исходного типа.
- `preview_create_sheets`: формат определяется загруженной основной надписью. Допускаются пустые листы; `views=[]`. При размещении проверяются фактические габариты листа.
- `preview_create_sections`: вертикальное задание размеров либо `box` с полями `origin`, `right`, `up`, `direction`, `min`, `max`. Базис должен быть ортонормальным и правым; `min`/`max` задаются в локальных координатах объёма, в метрах.

## Спецификации

1. Получите категорию из `get_fill_and_line_patterns` или существующих элементов.
2. Вызовите `get_schedulable_fields` с `categoryId` либо `scheduleId`. Для категории создаётся временная спецификация с последующим откатом; ответ находится в `result`. Для существующей спецификации ответ возвращается непосредственно.
3. Передайте выбранные пары `parameterId`/`fieldType` в `preview_create_schedule`, затем примените план.
4. Получите реальные `fieldId` через `get_schedule_definition`.
5. Настройте `preview_modify_schedule`: `filters`, `sortGroups`, `isItemized`, `showGrandTotal`.

Массив `filters` или `sortGroups` заменяет соответствующий список целиком. Пустой массив очищает его; отсутствие поля сохраняет настройки. Предпросмотр возвращает состояние до и после. Для группировки используйте `isItemized=false` и поля `sortGroups`; доступны заголовки, итоги групп и пустые строки.

Для фильтров указываются `fieldId`, `operator`, `valueType` и `value`. Поддерживаются строка, целое число, вещественное число и ElementId. Числа измеряемых величин могут содержать `unitId`. Допустимость сравнения и ограничения конкретного типа спецификации проверяет Revit.

## Графика и аннотации

`get_fill_and_line_patterns` возвращает штриховки, типы линий и категории. `preview_override_graphics` настраивает элементы **или** категории одного вида: цвет/вес/тип линий проекции, передний план штриховки поверхности и сечения, прозрачность, детализацию и полутона. Для переопределений выбирайте штриховки типа `Drafting`. Непереданные свойства сохраняются.

`get_annotation_categories` читает категории аннотаций на виде. `preview_isolate_annotations` и соответствующий `apply` временно изолируют переданные категории. `reset=true` снимает временную изоляцию и скрытие. Это реализация через временную изоляцию категорий Revit 2026; настройки функции Isolate Annotations из более новых версий Revit не используются.

## Экспорт

`export_views` поддерживает PNG, JPG, BMP, TIFF, PDF и CSV. Все `viewIds` одного запроса используют один формат; для CSV передавайте спецификации. PDF создаётся отдельно для каждого вида. `scope=activeView` экспортирует активный вид; `scope=visibleRegion` — видимую область для изображений.

`export_model` поддерживает IFC и gbXML. Для gbXML в проекте должна существовать совместимая энергетическая модель; автоматически она не создаётся. Изменения документа, которые выполняет экспортёр, откатываются.

Экспорт создаёт новую подпапку в `directory` и возвращает фактические пути файлов. Существующие файлы не перезаписываются. Доступность экспортёров зависит от установленного Revit и компонентов экспорта.
