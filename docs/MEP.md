# Трубы, воздуховоды и соединения

[← Руководство](USAGE.md)

## Создание участков

`list_mep_types` возвращает существующие типы труб, гибких труб, воздуховодов, систем и уровни. Для прямого участка передайте выбранные ID, начало, конец и размер сечения в `preview_create_mep`, затем примените план через `apply_create_mep`. Координаты и размеры задаются в метрах. Один пакет содержит до 50 участков; прямые и гибкие трубы можно объединять в одном пакете.

Создание участка не соединяет его автоматически с соседними элементами.

## Гибкие подводки

Гибкие трубы создаются как нативные `FlexPipe` в Revit 2026. Требуется полный пакет `0.0.2` с загрузчиком `0.0.2.9` и соответствующей схемой MCP. Установите пакет при закрытом Revit и перезапустите MCP-клиент.

Выберите `typeId` из `list_mep_types.flexPipeTypes`, `systemTypeId` из `pipingSystems` и уровень из `levels`. Обычный `PipeType` для гибкой подводки не принимается. Если список типов пуст, сначала подготовьте тип гибкой трубы в Revit.

Пример `preview_create_mep`; ID замените данными проекта:

```json
{
  "segments": [{
    "kind": "flexPipe",
    "typeId": 101,
    "systemTypeId": 202,
    "levelId": 303,
    "diameterMeters": 0.015,
    "points": [
      {"xMeters": 0, "yMeters": 0, "zMeters": 1},
      {"xMeters": 0.3, "yMeters": 0.15, "zMeters": 1},
      {"xMeters": 0.6, "yMeters": 0, "zMeters": 1}
    ],
    "startTangent": {"x": 1, "y": 0, "z": 0},
    "endTangent": {"x": 1, "y": 0, "z": 0}
  }]
}
```

`points` содержит от 2 до 100 точек в метрах от внутреннего начала Revit. Точки не повторяются; расстояние между соседними точками и между концами — не менее 0,01 м. Длина контрольной ломаной и фактическая длина трубы ограничены 300 м; диаметр — 0,001–3 м. Размер должен поддерживаться типом и Revit.

`startTangent` и `endTangent` необязательны и независимы: можно задать направление только на одном конце. Это безразмерные векторы в осях проекта, нормализуемые перед передачей Revit. Нулевые векторы отклоняются. Без явной касательной направление выбирает Revit. Радиус изгиба инструмент не рассчитывает; форму сплайна проверьте в модели.

Создание использует точки маршрута; после регенерации и commit проверяются их сохранность по порядку, координаты концов, заданные направления, тип, система, уровень, диаметр и два свободных круглых коннектора ВК. При несовпадении откатывается весь пакет. Revit может добавить свои контрольные точки, но не потерять заданные.

В `preview.result.segments` возвращаются `kind`, ID/UniqueId, `diameterMeters`, фактическая `lengthMeters`, `controlPolylineLengthMeters`, итоговые `points`, касательные и `connectors`. Все ID созданных объектов в preview временные. Завершите через `apply_create_mep`, затем используйте ID из `result.segments` и заново прочитайте `list_mep_connectors`.

Для подключения концов используйте отдельный `preview_connect_mep` / `apply_connect_mep`. При прямом соединении задайте маршрут и касательные так, чтобы концы совпадали, имели противоположные наружные направления и одинаковый диаметр. Подводка не перемещает существующее оборудование, не подключается автоматически и не подбирает переходы между разными диаметрами.

## Чтение коннекторов

Найдите элементы через `search_elements` или прочитайте текущее выделение. Вызовите `list_mep_connectors` с `elementIds` (до 50 уникальных ID). `unusedOnly: true` оставляет только свободные коннекторы.

Ответ содержит физические концевые коннекторы ОВ/ВК: `elementId`, `connectorId`, положение, направление наружной нормали, форму и размеры сечения, классификацию системы, состояние соединения и соседние коннекторы. Поддерживаются трубы, воздуховоды и семейства с MEP-моделью, включая фитинги и оборудование. Электрические и логические коннекторы в ответ не входят.

Используйте `connectorId` из ответа, а не номер строки или положение коннектора в массиве. После изменения геометрии прочитайте коннекторы заново.

## Соединение

Передайте две ссылки и явный способ соединения в `preview_connect_mep`. Пример структуры аргументов; ID нужно заменить значениями из модели:

```json
{
  "first": { "elementId": 101, "connectorId": 0 },
  "second": { "elementId": 202, "connectorId": 1 },
  "fitting": "elbow"
}
```

| `fitting` | Назначение |
| --- | --- |
| `direct` | Прямое соединение совпадающих концов с противоположными направлениями и одинаковым сечением. Для прямоугольного и овального сечения оси профилей должны совпадать. |
| `elbow` | Отвод между двумя участками. Допустимость угла и расстояния проверяет Revit. |
| `union` | Соединительная муфта одинакового сечения. Один из элементов должен быть трубой или воздуховодом. |
| `transition` | Переход между сечениями. Один из элементов должен быть трубой или воздуховодом. |

Оба коннектора должны быть свободными, принадлежать разным элементам и одной области ОВ или ВК. Закреплённые элементы и элементы групп не изменяются. Для прямого соединения допустимое расхождение положений — 0,1 мм; автоматическое перемещение оборудования и участков не выполняется.

Тип фитинга выбирает Revit по доступным семействам и настройкам трассировки. При создании фитинга Revit может изменить прилегающие участки. Предпросмотр возвращает состояние коннекторов до и после операции, ID и тип созданного фитинга; все изменения предпросмотра откатываются. ID созданного фитинга в preview временный.

Просмотрите результат, затем вызовите `apply_connect_mep` с полученным `planId`. Изменения выполняются одной транзакцией с подтверждением по текущей настройке плагина. Несовместимость коннекторов, отсутствие подходящего фитинга или неустановленное соединение отменяют операцию. После применения повторно прочитайте коннекторы и проверьте геометрию в Revit.

## Ограничения

Соединение не строит трассу между удалёнными точками, не разрывает существующие соединения, не создаёт тройники, врезки или ответвления и не корректирует уклон сети. Доступность фитинга зависит от семейств и настроек конкретного проекта. Перед рабочим применением проверьте нужные сочетания типов и размеров на копии RVT.
