# Брендинг

[← Revit MCP](../README.md)

Название продукта — **Revit MCP**, издатель — **OOXGN**. Вкладка и рабочие окна используют название продукта. Логотип издателя размещается в идентификационных элементах и документации.

## Знаки и цвета

В `docs/assets/` находятся готовые светлые и тёмные SVG-знаки OOXGN из AutocadTools. Их контуры, пропорции и интервалы сохраняются. Контур монограммы также используется в значке подключения; это повторное использование готового знака.

| Назначение | Цвет |
| --- | --- |
| Чёрный / поля | `#000000` |
| Графит / поверхности | `#2B2B2B` |
| Основной текст | `#FAF9F7` |
| Светлые разделители | `#D9D9D9` |
| Вспомогательные элементы | `#9CA3AF` |
| Функциональный серый | `#6B7280` |

Установщик использует общую тему `SetupTheme.cs`, Segoe UI, плоские кнопки и системные цвета при высокой контрастности. Диалоги Revit используют нативный TaskDialog и тему самого Revit. Новые шрифты в поставку не включаются.

## Графические материалы

Существующие знаки OOXGN готовы к использованию. Значок автоподтверждения сохраняет функциональную галочку в монохромной палитре. Специальная продуктовая иконка, индивидуальная ICO-иконка EXE и обложки пока отсутствуют; установщик использует стандартный значок приложения Windows.

Подробные английские промпты, сетки, варианты и требования к экспорту перечислены в [ASSET-PROMPTS.en.md](ASSET-PROMPTS.en.md). Эти промпты являются техническим заданием на новые материалы; они не обозначают наличие готовых изображений.
