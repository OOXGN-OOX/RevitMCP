# Запись параметров и ссылок ElementId

[← Инструменты модели](MODEL.md)

Поддержка прямой записи `ElementId` требует полного пакета `0.0.2` с загрузчиком `0.0.2.8` и соответствующим MCP-сервером. Установите его при закрытом Revit и перезапустите MCP-клиент. Горячее обновление рабочей DLL не добавляет поля и инструменты сервера.

## Выбор параметра и значения

Прочитайте `get_element_properties`. Возвращаемые `ownerId`, `scope`, `id`, `guid`, `storageType`, `rawValue` и `readOnly` позволяют выбрать владельца и точный параметр.

`get_parameter_value_options` возвращает допустимые значения параметра `ElementId`. Для выбора вложенного семейства, например «Питание», используются нативные варианты [Family.GetFamilyTypeParameterValues](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/a9c8ff23-17ec-1b87-e58a-4be589217766.htm). В список входят обычные типы и `NestedFamilyTypeReference`, которые не видны через стандартный поиск FamilySymbol. Для материала возвращается список материалов.

```json
{
  "elementId": 101,
  "parameterName": "Питание",
  "parameterScope": "type",
  "offset": 0,
  "limit": 100
}
```

Замените `101` реальным ID. `parameterScope` — `instance` по умолчанию или `type`; используйте область из прочитанных свойств. Вместо имени можно передать ровно один `parameterId` или `parameterGuid`. Совпадающие имена параметров требуют точного ID или GUID.

Ответ содержит `ownerId`, `parameterId`, `current`, `items`, `totalCount`, `hasMore` и `exhaustive`. Значения включают ID, его точную строку `elementIdText`, UniqueId, имя, семейство, тип и класс Revit. Перечисляются положительные ссылки; служебные отрицательные значения проверяются через preview отдельно. При `hasMore=true` запросите следующую страницу. `exhaustive=false` означает, что для такого вида ссылки нет перечислителя: выберите существующий ID через соответствующие инструменты чтения. Пустой список в этом случае не доказывает отсутствие допустимых значений.

## Предпросмотр и применение

Передайте выбранный из списка ID в `preview_set_parameter`:

```json
{
  "elementIds": [101],
  "parameterName": "Питание",
  "parameterScope": "type",
  "elementIdValue": 1001
}
```

Для ссылок используйте `elementIdValue` или целочисленную строку `value`, например `"1001"`. Отображаемое имя вроде `"230 В"` ссылочным значением не является. Число ограничено точным диапазоном JavaScript; 64-битные ID вне него передаются строкой `value` из `elementIdText`. Значение `0` отклоняется. `-1` и другие служебные отрицательные ID принимаются только там, где их разрешает соответствующий параметр Revit; preview проверяет присвоение.

Для обычных строковых, целочисленных и дробных параметров сохраняется поле `value` со строкой. Дробное значение разбирается по единицам проекта Revit. Передавать `value` и `elementIdValue` одновременно нельзя. Поле `elementIdValue` принимается только параметром с `StorageType.ElementId`.

Preview выполняет пробную транзакцию, регенерацию и commit с последующим откатом группы. Проверяется существование положительной ссылки, принадлежность типа списку применимых значений, соответствие материала и фактическое значение после commit. Результат находится в `preview.result`: `changes` содержит ID владельцев и параметров, исходные/итоговые raw и display значения; `skipped` объясняет недоступные цели. Если подходящих целей нет, `planCreated=false`.

Завершите через `apply_parameter_plan` с `planId`. Применение использует сохранённые значения; новый ID при apply не передаётся. Проверяются документ, ревизия, ID/UniqueId владельцев, идентичность параметров и прежние значения. Ошибка или несовпадение после commit откатывает всю группу транзакций.

В области `type` несколько выбранных экземпляров одного типа изменяют общего владельца один раз. Изменение типа действует на все использующие его экземпляры. Параметры только для чтения и управляемые формулой не обходятся. Текущие проектные и семейные документы поддерживаются для обычных параметров элементов; параметры FamilyManager внутри RFA редактируются отдельными `preview_build_family` / `apply_build_family`.
